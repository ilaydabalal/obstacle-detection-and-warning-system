# 👁️ Engel Algılama ve Uyarı Sistemi | Obstacle Detection and Warning System (2025)

---

<a name="türkçe"></a>
Arduino, HC-SR04 ultrasonik mesafe sensörü ve buzzer donanımlarını kullanarak mesafe bazlı uyarı üreten gömülü bir sistem geliştirdim. Sensörden gelen ses dalgası sürelerini mesafeye çeviren C++ tabanlı yazılım mantığı kurarak dinamik frekansta sesli ikaz mekanizması oluşturudum.

###  Özellikler
- Ultrasonik sensör ile anlık mesafe ölçümü
- Gelen ses dalgası sürelerini santimetreye çeviren optimize edilmiş C++ algoritmaları
- Ölçülen mesafeye göre dinamik frekans ve gecikmelerle çalışan buzzer ikaz mekanizması
